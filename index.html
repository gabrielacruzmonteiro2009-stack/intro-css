O que é CSS?

O CSS significa Cascading Style Sheets, ou Folhas de estilos em cascata.

Sobre CSS

Linguagem responsável por definir a aparência visual e organização dos elementos na tela.

Como aplicar o CSS?

Para o CSS, temos três abordagens:

  • CSS Inline
  • CSS Interno
  • CSS Externo

O que da para fazer com o CSS?

O CSS não serve apenas para colocar cor na página. Ele controla:

  • cores
  • fontes
  • tamanhos
  • espaçamentos
  • sombras
  • bordas
  • posicionamento
  • responsividade
  • animção
  • transições

Aplicando o CSS Inline

Nessa abordagem, o CSS é colocado diretamente no elemento HTML através do atributo style

Aplicando CSS Interno

Nessa abordagem, o CSS é aplicado dentro de uma tag < style > dentro do < head > do documento HTML.

Aplicando o CSS Externo

Nesssa abordagem, os estilos do CSS ficam concentrados em um arquivo separado.

Para conectar esse arquivo ao HTML, utlizamos o elemento de < link > head < no > da página
